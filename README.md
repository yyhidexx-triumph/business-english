# English Cards 複数教材版

GitHubリポジトリ内の既存ファイルを、このZIP内のファイルで置き換えてください。

## 教材選択
- 全教材
- ビジネスに効く英単語101
- 日常の英熟語

個別教材または全教材を選び、順番再生・ランダム再生（重複なし）ができます。

## 今後の追加
1. 同じ構造の教材JSONを作成します。
2. GitHubへJSONをアップロードします。
3. modules.json の modules 配列へ id/title/file を1件追加します。

一時的な追加なら、画面の「追加教材JSON」から読み込めます。ただし再読み込み後も常設するには modules.json への登録が必要です。
