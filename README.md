# Business English Cards

元データ: マージ版m3..xls / 「ビジネスに効く英単語101」
収録: 101カテゴリー、1525カード

## スマホへの入れ方
1. このフォルダー一式をHTTPS対応の静的Webサーバーに配置します。
2. SafariまたはChromeでURLを開きます。
3. iPhoneは共有メニューの「ホーム画面に追加」、Androidは「アプリをインストール」または「ホーム画面に追加」を選びます。

## 今後の教材追加
`addon-template.json` と同じ構造の追加教材を作り、アプリ内の「追加教材（JSON）」から読み込めます。別シートを追加教材に変換すれば、アプリ本体を作り直す必要はありません。
